# ServerWatch

[![Downloads](https://img.shields.io/github/downloads/BigPaperBear/ServerWatch/total?style=flat-square&label=Downloads)](https://github.com/BigPaperBear/ServerWatch/releases)

A World of Warcraft addon for OctoWoW. It warns you when the server stops responding.

Originally created by shunrai4714.

## What it does

ServerWatch checks your connection to the game server. If the server stops answering, a big warning shows on your screen and plays a sound. When the server answers again, the warning goes away and you get a message that the connection is back.

## Slash Commands

`/serverwatch status` or `/swatch status`: Shows if the monitor is active, if it thinks you are disconnected, and how long since the server last answered.

`/serverwatch test` or `/swatch test`: Turns the warning on or off, so you can test that it works.

## Installation

1. Copy the ServerWatch folder into your Interface/AddOns folder.
2. Turn on the addon in the AddOns list on the character select screen.
